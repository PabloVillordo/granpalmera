Especificación del sistema de coordenadas
Parece que los datos de entrada no contienen información sobre el sistema de coordenadas utilizado. Si sabe que sus datos no utilizan ningún sistema de coordenadas geográficas o cartográficas conocido, o si considera que no necesita definir uno para la conversión, puede omitir este paso. De lo contrario, puede definirlo mediante las opciones que se muestran a continuación. Tenga en cuenta que si no se especifica el sistema de coordenadas de sus datos de entrada, no será posible realizar conversiones a algunos formatos que utilizan un sistema de coordenadas específico, como KML, KMZ, GeoJSON, GPX, MBTiles, entre otros.

Si no está seguro del sistema de coordenadas que utilizan sus datos de entrada, intente primero definir un área que se corresponda aproximadamente con la extensión de sus datos dibujándola en un mapa. Después, la lista de sistemas de coordenadas se reducirá a aquellos que se usan comúnmente en esa área, ordenados por frecuencia de uso. Esto aumentará la probabilidad de que elija el correcto.

Si conoce el sistema de coordenadas de referencia que utilizan sus datos de entrada, puede seleccionarlo de la lista de sistemas de coordenadas potenciales.

En ambos casos, compruebe en el siguiente mapa general que el área de cobertura de sus datos se muestra en la ubicación correcta. Si no es así, probablemente se haya seleccionado un sistema de coordenadas incorrecto y sea necesario elegir otro.
